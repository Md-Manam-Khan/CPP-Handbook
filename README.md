## 📌 About

**CPP-Handbook** is where I'm keeping my C++ notes as I learn the language from ChatGPT. Every `.txt` file in here is a lesson straight from that learning process — I ask, ChatGPT teaches, I save the text. This is not a finished or pre-planned curriculum; it grows one lesson at a time as I actually learn the material, until I have finished learning!

## 🖥️ How to Use

Clone the repo and open any lesson file directly — no build step, no dependencies, just plain text:

```bash
git clone https://github.com/Md-Manam-Khan/CPP-Handbook.git
cd CPP-Handbook
```

Read lessons in order for the intended progression, or jump to whichever topic you need.

## 🚀 Why This Project?

I'm learning C++ through a guided, lesson-by-lesson conversation with ChatGPT. Rather than let that knowledge stay buried in chat history, I save each lesson as plain text here — so this repo is effectively my learning log. It's not written by me from scratch and it's not finished; it's uploaded incrementally, lesson by lesson, as I actually go through them.
